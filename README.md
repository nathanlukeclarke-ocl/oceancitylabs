# Ocean City Labs — Static landing page

A responsive, single-page website built with plain HTML, CSS and a small amount of JavaScript. No build step or backend required.

## Publish with GitHub Pages

1. Create a public GitHub repository (for example `ocean-city-labs`).
2. Upload the **contents** of this folder to the repository root (`index.html`, `styles.css`, `script.js`, `assets/`).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**. Save.
5. GitHub will provide a Pages URL once the site is deployed. You can optionally configure a custom domain under Pages.

## Before publishing

- **IMPORTANT:** In `index.html`, replace `hello@example.com` in the contact button with your real company email address.
- Review venture descriptions and their “in development” status for accuracy.
- The OCL branding is represented by a clean typographic monogram in the header and hero. The previously generated OCL logo is also included as `assets/ocl-logo.png` for optional use.
- The font is loaded from Google Fonts. Replace with local/system fonts if you prefer not to make an external font request.

## Edit content

All text is in `index.html`. Colours, layout and typography are in `styles.css`.

The original OCL geometric logo is in assets/ocl-logo.png and is used in the header, hero and footer.


## Transparent logo update
The header, hero and footer use assets/ocl-logo-transparent.png. The main logo panel has a transparent background and no panel shadow, allowing the existing hero background to show through. The original asset is retained as assets/ocl-logo.png.

The circular backdrop behind the hero logo uses a pale ice-blue gradient for contrast with the navy and turquoise logo.
